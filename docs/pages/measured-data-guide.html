PADPD · 实测数据接口指南

完整实测源:采集清单 → npz 容器 → Spectre/台架流程 → 导入验证

一份实测数据包决定了平台是"只能跑基础建模"还是"整套能力全部点亮"。本文回答四个连续的问题:需要采什么、装进什么格式、从电路仿真/台架怎么得到、导入后如何验证。规范性定义在仓库 docs/02_data_interface.md §9 与手册第 4 章,本文是工作流视角的整合。

1完整实测源需要包含什么

1.1 最低可用集(有这些就能开工)

内容要求
对齐的 (x, y) IQ 对PA 输入/输出复基带;粗对齐即可(导入时可自动消整数+分数时延),增益不要预归一,注明是否已对齐
采样率 fs必须准确;过采样 ≥3–5× 信号带宽,否则失真肩带被截,ACLR/Mask 不可信
三分割train / val / test(或给足长度由导入端切);验证集须为不同数据的同类波形
采集条件DPD-off 原始采集(或注明 DPD/CFR 在环状态)、工作点(输入功率/回退)、目标增益

这一层解锁:经典/样条/神经建模 + ILA DPD + OpenDPD 口径评估。

1.2 五个可选采集组——每多一组,点亮一类能力

采集组内容解锁对应工具
burst 突发高低功率交替激励(段长 ≳ 最慢 τ)慢状态建模——平稳采集里热状态不可观测StateConditionedSpline
step 阶跃探针恒包络阶跃序列录制(探针幅度须在压缩区)离线辨识 τ → state_alphasidentify_gain_modulation_capture
cal_rx 旁路标定已知信号只过观测 RX(旁路 PA)RX 纹波/RX IQ 去嵌(盲估原理上不可辨识)calibrate_rx_path
atten 衰减步进同一驱动、RX 衰减差已知的两次采集分离 RX 立方 κ(与 PA 立方近共线,盲拟合分不开)calibrate_rx_im3
operating_points每工况点一组 (x,y) + 工况标量(温度/偏置/供电)跨工况系数调度CoefficientScheduler

1.3 元数据清单(一个都不贵,缺了很疼)

  • 参考平面:y 是 PA 输出、耦合器后、还是 RX ADC?观测链上有什么(衰减器标称、观测带宽);
  • 本振关系:TX/RX 是否共本振(决定去嵌要不要开 CFO 校正);
  • 绝对功率标定:满量程对应 dBm——线性度分析用归一化 IQ 够了,效率/联合设计需要绝对标度;
  • 温度/时间戳(漂移研究)、ADC 位数、是否预滤波、CFR/DPD 在环状态。

2npz 容器格式

就是 NumPy 标准 .npz:一个普通 ZIP,内部每个命名数组是一个 NPY 文件(魔数 \x93NUMPY + dtype/shape 头 + 原始数据)。没有私有格式,任何能写 NumPy 数组的环境都能生成,numpy.load 即读。

2.1 数组命名 schema

数组名dtype / shape说明
x, ycomplex64, (N,)必备:对齐的 PA 输入/输出基带 IQ
sample_rate_hzfloat64 标量必备:采样率
metaUnicode 字符串标量可选:Python dict 的 repr() 文本
burst_x / burst_ycomplex64可选组:突发采集
step_x / step_ycomplex64可选组:阶跃探针录制
cal_rx_ref / cal_rx_obscomplex64可选组:旁路 PA 标定
atten_ref / atten_hi / atten_lo + atten_step_dbcomplex64 + float64 标量可选组:衰减步进
op_conditions + op0_x/y, op1_x/y, …float64 (K,) + complex64可选组:每工况一对

缺哪组就不写哪个数组——导入端按数组名判断完整度;普通 {x, y, sample_rate_hz} 三件套就是合法退化情形(即 IQDataset 格式,双向兼容)。

2.2 两个刻意的设计决定

  • meta 不用 pickle:存 repr() 字符串、ast.literal_eval 解析、全程 allow_pickle=False——接收外部数据文件的导入功能不留反序列化执行代码的口子;
  • IQ 存 complex64(写入降精度 ~1e-7,远低于测量噪声;加载升回 complex128)——体积减半,1 MB 量级装下几十万复样本。

3.1 主采集:包络瞬态

  1. Testbench:基带 I/Q PWL 激励 → 理想 IQ 调制器(Verilog-A,刻意理想——除非要把真实混频器的镜像/LO 泄漏包进 DUT)→ PA(建议后仿提取网表,偏置/匹配网络完整:电记忆主要来自偏置网络,理想偏置会把记忆仿没)→ 负载;
  2. padpd 生成波形(OFDM+CFR,单位 RMS)按目标输入功率定标,导出 PWL 喂 vsource type=pwl;
  3. envlp 分析(fund=载频,harms=1,errpreset=conservative),取 PA 输出端口基波复包络,按 fs 均匀采样;
  4. 导出 time, i_in, q_in, i_out, q_out CSV(即现有 Cadence 导入列约定);丢弃起始瞬态段;满量程 dBm 记入 meta。

3.2 burst / step:必须电热协同,否则白仿

这两组的信息全在热状态动力学里——纯电学网表的阶跃响应是平的,工具会如实判"无增益调制"(有效的对照,但不是 τ)。途径按可得性:

  1. PDK 器件自热开关(GaN/SOI 常见 sht),多为单指数;
  2. 显式 Rth-Cth 热网络:耗散功率注入梯形网络、温度节点反馈器件 temp——能仿出多极点 τ(芯片 µs 级 + 封装 ms 级),与 ThermalReferencePA 结构一一对应;
  3. 电热场求解器协同(最准最贵)。
探针要点:step_probe_drive 的 a_hi 必须定标到压缩区(小信号探针对增益调制几乎全盲);t_obs 盖住最慢预期 τ 的 3–5 倍——真实器件可到 ms 级,恒包络探针不需要宽带 fs,可以降采样率换仿真时长。burst 段长同理 ≳ 最慢 τ。

3.3 cal_rx / atten:标定的是"观测接收机"

  • 反馈 RX 同芯片(产品形态):单独仿 RX 链——已知 IQ 旁路 PA 直灌得 cal_rx;同一驱动幅度乘 10^(−step/20) 再跑一次得 atten(RX 网表带真实非线性,κ 自然物理);
  • 观测是仪器(VSA):这两组在 Spectre 里没有对应物——来自台架(旁路线缆 + 步进衰减器),或信任仪器自校准直接省略,清单显示 ✗ 即可。

3.4 建议的最小可行顺序

  1. HB 双音 + HB 功率扫/S 参数(小时级):双音表定记忆深度;load_hb_pa 装配 WH 模型预演整条 DPD 链(scripts/import_hb_pa.py --demo);
  2. 主采集包络仿真:得到第一个可拟合数据集;
  3. 电热 step/burst:DPD 规格含热瞬态要求时;
  4. RX 两组留给台架。

GUI 步骤:数据管理页 → 上传 npz →勾选"自动延迟对齐"→ 加载;确认完整度清单五项 ✓;点「运行完整源工具」核对上表;建模页用该源拟合 Spline-MP-WL 验证镜像分支收益。

三个已踩过的坑(采集设计同样适用): ① 状态模型评估的冷启动约定——单采集切分后,验证尾段带着前段的热历史,必须全信号预测、尾段打分,否则 +10 dB 会缩水成 +1; ② 冻结类校准的电平陷阱——耗散功率参考、RX-IM3 κ 这类"首采冻结"的量,标定采集必须在标称工作电平做,回退采集排第一会把参考冻错两个量级; ③ 衰减步进两采集须同一驱动、PA 热状态一致(先热稳定再采),PA 失真才是共模、差分才干净。
