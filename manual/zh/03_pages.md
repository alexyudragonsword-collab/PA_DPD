# 3. 功能页操作指南

本章逐页说明"输入什么、点什么、看什么"。实验页都用同一个模板:左侧参数、
右侧结果,下面先讲模板,再逐页讲各自的输入与读法。

## 3.0 实验页模板

- **参数**:按分组排成一列,只显示当前选择下有意义的输入(例如 DPD 选
  ILA 时不出现神经网络参数;合成源上不出现"PA 代理")。不常用的输入收在
  "高级设置"里。被隐藏的输入不会进入运行,也不会写进运行记录。
- **判定卡**:每张卡给出数值、限值、余量与"通过 / 不通过",左侧色条同义;
  有对照组(例如无 DPD)时一并给出对照值及其判定。限值来自顶栏的项目
  Spec;改 Spec 后已有结果**立即按新限值重判**,不必重跑。没有限值的
  卡只是读数,不标通过与否。
- **图**:悬停显示光标处每条曲线的读数;拖选一个矩形放大,双击复原。
  右轴的量放在下方共享 x 轴的小图里,不与左轴挤在同一张图上。
- **来源**:结果底部给出 run 编号、参数、数据源与用时。"复现"把这些参数
  填回左侧;"在结果比较中打开"跳到比较页并选中同类最近两次运行。
- **过期提示**:运行后改了参数或切换了数据源,结果上方出现黄色提示——
  下面仍是上一次的结果。点"重新运行"或"复现"。

## 3.2 波形

生成 802.11be 风格 OFDM 基带波形。

- **输入**:带宽(20–320 MHz)、调制(256/1024/4096-QAM)、OFDM 符号数;
  可选 **CFR 削峰**及目标 PAPR(dB);随机种子在高级设置里。
- **输出**:采样率、FFT 与有效子载波、PAPR(开 CFR 时还有削峰后 PAPR 与
  EVM 代价);频谱、CCDF、星座、时域四个图页,开 CFR 时叠加削峰前后。
- **导出 .npz**:IQDataset 格式,可在数据源页重新载入。

![波形:CFR 前后频谱](assets/qt_waveform.png)

## 3.3 数据源

工作区里的数据源列表,"●"标出当前数据源(双击或"设为当前"切换,顶栏
数据源也可切换)。数据源以**引用**保存——合成源存生成参数,实测源存文件
路径与加载方式——重启后仍在,首次使用时才加载。

- **新建合成源**:带宽、调制、符号数、CFR、PA 驱动 drive、TX 前端损伤
  (IQ 失衡 / LO 泄漏 / C-IM3),"添加合成源"后成为当前数据源。
- **导入实测**:打开 Cadence CSV / MATLAB `.mat` / IQDataset `.npz`(按
  后缀识别,可勾选**自动延迟对齐**,见第 4 章);OpenDPD 目录选数据集后
  "加载数据集";"载入完整源示例"载入含五个采集组的演示容器。
- **预览**:采样率、train/val/test 样本数、主带宽、调制;输入/输出频谱与
  AM-AM/AM-PM;完整源列出各采集组,并可"运行完整源工具"(τ 辨识、状态
  样条、RX 标定、调度器)。

![数据源:完整源示例与采集组](assets/qt_data.png)

## 3.4 PA 模型

在当前数据源上拟合 PA 行为模型。

- **经典 (LS)**:类型(MP / GMP / DDR、OpenDPD 约 500 参数预设
  MP-500 / GMP-510 / DDR-140、样条族等)、非线性阶数、记忆深度;闭式解,
  秒级。
- **神经网络**:结构(DGRU / GRU / TCN)、隐藏单元、训练轮数;训练时进度
  显示当前轮次与验证 NMSE。未装 PyTorch 时选项下方直接提示。GUI 默认
  小参数用于交互实验,论文级训练请用 `scripts/train_neural_pa.py`。
- **输出**:测试 NMSE、参数量;实测 vs 预测频谱、AM-AM/AM-PM;神经模型
  另有训练曲线。
- **工作区中的模型**:页面底部列出已拟合的模型,带类型、数据源、NMSE、
  run 编号与是否已保存。模型自动保存进工作区,是 DPD 的评估代理和部署页
  的输入。

![PA 模型:GMP-510 拟合结果](assets/qt_modeling.png)

## 3.5 DPD

在当前数据源上辨识预失真器并按 Spec 判定。

- **算法**:**ILA · 经典 LS**——选基函数(GMP-510 / DDR-140 / MP-500 /
  GMP / DDR / MP / 样条族);**DLA · 神经直学**——需要一个神经 PA 代理,
  预失真器与冻结代理级联梯度直训。
- **PA 代理**:只在需要时出现——DLA,或当前数据源是实测源(实测数据没有
  可解调的真值,DPD 后的输出要用模型预测;应选神经代理,见 6.3 节)。
- **判定**:EVM、ACLR 较差一侧、**发射 Mask 带外余量**(到 802.11 模板的
  最小距离,正值为通过),各带无 DPD 的对照;表格给出上下邻道 ACLR 与
  改善量。评估口径随数据源自动切换(合成源用星座 EVM;OpenDPD 源用其发表
  口径),写在结果下方。

![DPD:ILA GMP-510,EVM -19.0 → -59.8 dB,Mask 余量 -7.2 → +18.7 dB](assets/qt_dpd.png)

> Mask 余量只看第一个模板拐点以外的频段。功率谱按带内峰值归一化,带内
> 恰好落在模板的 0 dB 上,把带内也算进去的话任何信号的余量都是 0.0。

## 3.6 部署

- **位宽扫描**:勾选工作区里的模型与位宽(W16–W8),bit-true 定点仿真;
  判定卡给出每个模型**NMSE 损失不超过 1 dB 的最窄位宽**;曲线与表格含
  每样本 MAC 与 GMAC/s 估计,虚线为浮点基线。勾选"同时扫描 LUT 深度"时,
  带增益曲线的样条/MP 模型另扫查表深度。
- **导出交接产物…**:选模型与位宽、选目录,生成整数系数 JSON、bit-true
  参考向量 CSV;经典模型另生成 `rtl/dpd_mac.v` 并用 Icarus Verilog 逐位
  验证,神经模型导出 ONNX 并做数值验证。

![部署:位宽 vs 精度扫描](assets/qt_deploy.png)

## 3.7 专题实验

每个专题实验都是独立页面,用同一个模板。

- **增益调制**:恒包络阶跃探针辨识热/陷阱时间常数,并用辨识出的 α 配置
  状态条件化样条;虚拟 DUT 可选自热(thermal)或静态对照(static)。
- **自适应跟踪**:漂移 PA 上逐块比较自适应 DPD(RLS / 白化 RLS / APA)与
  冻结批处理 DPD 的 EVM。
- **前端三环**:漂移 PA + TX 镜像与 LO 泄漏 + 被污染的观测环回,比较仅去嵌
  与三环联合(QMC + 去嵌 + 自适应 DPD)。原始环回在满漂移时失效、EVM
  为正值,写在说明框里而不画进图,免得把另两条曲线压扁。
- **联合设计**:给定 EVM 目标与 DPD 系数预算扫描 PA 工作点;红色区域为
  不可行(不可逆或超预算),两张卡对比"顺序设计(先冲效率)"与"联合设计
  (预算内最高效率)"。数秒到一分钟,视机器而定。
- **可微联合寻优**:内层闭式 LS-DPD、外层对 drive 求梯度,在 EVM 约束下
  找最高效率(需要 PyTorch,未安装时不出现)。
- **双音诊断**:读一张 IM3 随音间距变化的表,在训练 DPD 之前预判记忆强度
  与建议记忆深度;留空用内置示例。

![联合设计:Pareto 扫描与可行域](assets/qt_codesign.png)
